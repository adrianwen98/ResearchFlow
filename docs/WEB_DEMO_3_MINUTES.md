# 独立 ResearchFlow 工作台：2–3 分钟求职演示

演示前双击 `run_web_windows.bat`，打开 http://127.0.0.1:8000/ 。已有案例展示不会调用付费模型。

**0:00–0:25｜产品与任务。** 首页直接展示目标输入和可选验收标准，无需先点新建；指出开始按钮旁的真实预算与费用提示，不提交付费执行。说明 React 负责交互，FastAPI 负责任务生命周期，LangGraph 根据真实工具返回继续决策，工具来自 Playwright MCP 和本地文件模块。

**0:25–1:10｜自主操作与失败控制。** 左侧打开 `interaction_end_to_end` 历史真实验收。点击“执行详情”展开右侧，再展开 `browser_type`、`browser_click`、`browser_follow_link`、`browser_download`；展示实际参数和返回、一次下载前的页面引用失效，以及后续重新读取和成功下载。展开调整与恢复事件，结合原始证据说明曾终止 Python 进程并从同一 Checkpoint 恢复。必须说明这是已有真实记录，不伪装成现场重新执行；搜索结果通过已观察链接工具打开，不宣称其为原生 browser_click。

**1:10–1:50｜交付与核验。** 先看结果卡的真实完成状态、业务表/来源表/Markdown 下载入口，再看明确标注的报告原文摘录。收起详情或历史，切换数据预览确认真实负数。点击“逐项核对”直达需求验收，说明 needs_review 不等于 completed；只有文件、来源、报告摘录与全部需求有效，并由用户确认，才记录完成。

**1:50–2:20｜可用的数据交付。** 打开 `penguins_public_demo`，查看原始观测、物种样本数和体重均值。明确这是公开真实数据的免费脚本工具复现，不是自主大模型运行证明。说明 Excel 网页预览读取生成的实际文件，而不是手写表格数据。

**2:20–2:50｜工程可靠性。** 展开执行详情，指出真实请求预算、错误/重试和最近执行耗时；无记录的指标显示“—”。刷新保留任务选择。解释 SSE 事件游标、断线重连、REST 同步、服务端脱敏、路径白名单和绑定审批。敏感操作先 interrupt，拒绝或绑定审批后从原状态继续。

收尾可展示自动化验收记录和已知限制。不要在没有额度授权时临时执行或恢复任务，也不要把隔离离线 UI 测试服务当作现场真实 Agent 演示。

本轮任务优先 UX 验证：136 项 Python、18 项前端测试通过；本轮付费请求为 0。完整截图、操作对比与边界见 [UX 收尾记录](UX_OPTIMIZATION.md)。
