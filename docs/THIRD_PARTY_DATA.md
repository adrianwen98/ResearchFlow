# 公开演示数据来源

企鹅数据项目：[palmerpenguins](https://allisonhorst.github.io/palmerpenguins/)。原始CSV：[项目仓库数据](https://raw.githubusercontent.com/allisonhorst/palmerpenguins/main/inst/extdata/penguins.csv)。项目声明数据按CC0提供；引用Horst AM, Hill AP, Gorman KB (2020), doi:10.5281/zenodo.3960218。数据为2007–2009年观测样本，不是当前普查。

历史MCP案例的数据：[pandas官方测试XLSX](https://github.com/pandas-dev/pandas/blob/main/pandas/tests/io/data/excel/test1.xlsx)，属于pandas测试样本，不具有业务统计意义；上游项目许可证及说明以[pandas仓库](https://github.com/pandas-dev/pandas)为准。

公开演示的来源摘录来自已经实际读取的页面或文件。观察文件是白名单式原文节选，轨迹是精选事件；不冒充完整原始运行日志。模型原始研究报告保留原文，未为展示改写数字。
