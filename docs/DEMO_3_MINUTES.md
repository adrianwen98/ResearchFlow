# 2～3分钟演示流程

先运行Windows启动脚本。以下流程查看保存记录，不会调用付费模型。

**0:00–0:25 定位与输入。**“这是单Agent的网页研究与数据处理系统。控制图固定，具体工具和路径由模型根据观察选择。”点击查看真实演示，说明它是历史真实DeepSeek记录，不是本次现场跑模型。

**0:25–1:05 自主性与MCP。**打开执行过程，展开输入搜索、点击、下载工具的参数与返回。说明原生搜索按钮点击，搜索结果按观察ref跟随链接打开；不是写死结果URL。指出过期ref曾被拒绝，后续调整控件后下载成功。

**1:05–1:35 Harness与恢复。**展示20/20请求预算、35次逻辑工具、4次错误；指出原Python进程在下载后被终止，新进程使用同一task_id和SQLite恢复，文件哈希未变。旧完整证据保留在私人交付中，GitHub只有脱敏摘要。不要现场再次启动已耗尽预算任务。

**1:35–2:10 有价值的数据交付。**从任务历史打开企鹅公开数据演示，先声明“这是0 API的脚本工具复现，用来展示真实公开数据处理；自主性由前一个案例证明”。查看数据预览：344条记录、体重缺失2条、性别缺失11条，3种物种的样本数量和非缺失体重均值。解释样本数不是总体种群数，均值排除缺失值。

**2:10–2:40 正确完成。**展开逐项需求：程序检查、来源与用户内容判断分开。needs_review最后一步不点亮；需求未通过时确认按钮禁用，API也拒绝。审批按钮用于敏感操作，不能代替最终验收。

**2:40–3:00 边界与总结。**“重点是工具观察后的决策、真实MCP、累计预算和可恢复的交付。仍不支持任意网站写操作；历史模型的摘录登记需一次反馈。测试为离线工程验证，没有通用成功率。”
